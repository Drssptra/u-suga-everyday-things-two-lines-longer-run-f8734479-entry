A tiny Node program that writes a two-line explanation of a queue for a 10-year-old: a queue as a slow caterpillar made of people, inching forward one wiggle at a time — plus an honest second line about what the analogy maps (the single-file shuffle where nobody overtakes) and what it leaves out (people can step out of line whenever they like, while a caterpillar's segments never can).

## Run it

```sh
node main.ts
```
